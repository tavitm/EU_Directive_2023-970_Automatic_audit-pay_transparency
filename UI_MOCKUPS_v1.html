9. Key Design Patterns & Interaction Guidelines

✓ Form Validation & Error Handling

Inline Errors: Invalid salary field
✗ Must be greater than 0
Behavior: Submit button disabled until all errors cleared. Clear error message with fix suggestion.

🔐 RBAC Visibility Rules

Screen Element HR Specialist Manager Compliance Employee
Job Management ✓ Full ✓ Read (own dept) ✓ Read only ✗
Employee List ✓ Full ✓ (own dept) ✓ Read only ✗ (sees own pseudonym only)
Gap Analysis ✓ Full ✓ (own dept) ✓ Full ✗
Create Justification ✓ ✗ (approve only) ✗ (validate only) ✗
Art. 10 Employee Request ✗ (process only) ✗ ✓ Process ✓ Submit & read response

♿ Accessibility Standards (WCAG 2.1 AA)

  • Color + Labels: KPI cards use both color and text (not color alone)
  • Keyboard Navigation: Tab through all form fields, buttons keyboard-accessible
  • ARIA Labels: Screen reader support for role announcements (e.g., "alert" for error messages)
  • Contrast: All text meets 4.5:1 contrast ratio
  • Focus Indicators: Visible focus ring on all interactive elements
  • Form Validation: Clear error messages associated with fields (aria-describedby)
  • Table Headers: Table cells linked to headers for screen readers

📱 Responsive Design

Mobile (<576px)
Single column layout. Stacked forms. Touch-friendly buttons (44px min).
Tablet (576-992px)
2-column grids. Sidebar navigation collapses. Tables scroll horizontally.
Desktop (992px+)
3-4 column grids. Full sidebar. All features visible.

🛡️ Data Protection Visual Cues

  • Pseudonymization Badge: EMP_xxxxx labels show employee is pseudonymized
  • Audit Trail Icons: 🔒 icon next to immutable fields (cannot edit after approval)
  • Lock Icons: Locked fields show 🔒 with tooltip "Cannot modify after approval"
  • Encryption Status: HTTPS indicator always visible. "🔐 Encrypted" label on sensitive data
  • Compliance Badges: Art. 4 ✓, Art. 5 ✓, GDPR ✓ badges show compliance status
