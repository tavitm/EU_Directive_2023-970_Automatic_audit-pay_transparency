📊 1. Overview & Obiective

Descriere Proiect

Sistem web-based integrat pentru gestionarea salariaților, evaluarea obiectivă a posturilor și asigurarea conformității cu Directiva UE 2023/970 privind transparența salarială.

Obiective Principale

✓ Evaluare Obiectivă

  • Evaluare sistematică a posturilor
  • Clasificare în categorii valoare
  • Reducere subiectivității

✓ Transparență Salarială

  • Analiză diferențe salariale
  • Justificări obiective documentate
  • Identificare disparități

✓ Conformitate Legală

  • Respectare Directivă UE
  • Raportare la autorități
  • Audit trail complet

✓ Eficiență HR

  • Automatizare procese
  • Rapoarte inteligente
  • Reducere administrare

⚖️ 2. Scope & Cadru Legislativ

Cadrul Legislativ

Document Descriere Aspecte Cheie
CELEX 2023/970 Directiva UE - Pay Transparency Art. 4: Evaluare obiectivă; Art. 5-7: Justificări; Art. 9: Raportare
EM-proiect Legea RO Implementare în legislația română Adaptare la contextul legislativ RO, termen implementare
GDPR Protecția datelor personale Pseudonimizare, drepturi subiect, audit logging

Cerințe Funcționale Principale

Din Directiva UE 2023/970

  • Art. 4(4): Evaluare obiectivă a posturilor pe baza criteriilor precum competențe, efort, responsabilitate, condiții de muncă
  • Art. 5: Justificare în scris a oricărei diferențe salariale ≥ 5% pentru muncă egală
  • Art. 7: Plan măsuri corective pentru diferențe nejustificate
  • Art. 9(1): Raportare la autorități cu date agregate
  • Art. 10: Drepturi informare pentru salariați (pe cerere)

🏗️ 3. Arhitectură Sistem

Strategie Arhitecturală

Recomandare: Arhitectură Modulară (Microservices-friendly) cu 4 straturi principale:

Straturi Arhitecturii:

1. Frontend (UI/UX) - Dashboard, formulare, rapoarte interactive

2. API & Business Logic - Servicii REST/GraphQL, calcule, validări

3. Data Layer - Bază de date, cache, audit logging

4. Security & Compliance - Autentificare, autorizare, GDPR, audit

Principii Arhitecturale

  • ✓ Modularitate - Module independente, ușor integrabile
  • ✓ Scalabilitate - Suport pentru organizații mici → mari
  • ✓ Securitate - By-design, nu add-on
  • ✓ Compliance-first - Conformitate GDPR și Directivă built-in
  • ✓ Auditabilitate - Logging complet, trail inviolabil

Relații Cheie

Jobs (1:N) Job_Evaluations - Un post are mai multe evaluări (1 per criteriu)

Employees (N:1) Jobs - Mulți salariați pe același post

Employees (1:N) Salary_Components - Un salariat, multiple versiuni salariu

Jobs (N:1) Equal_Value_Categories - Postul aparține unei categorii de valoare egală

Salary_Analysis (1:N) Justifications - O analiză poate avea multiple justificări

🔄 6. Workflow-uri Principale

Workflow 1: Setup Inițial Evaluare Posturi

📌 Scopul: Evaluare obiectivă a tuturor posturilor și clasificare în categorii valoare egală

Pași:
  1. Inventariere: HR importă toate posturile active cu metadate (departament, nivel, etc.)
  2. Definire Criterii: Org. definește 7 criterii (competențe 25%, efort 15%, responsabilitate 25%, condiții 10%, complexitate 10%, autonomie 10%, impact 5%)
  3. Evaluare: Manager + HR evaluează fiecare post pe fiecare criteriu (scor 1-5)
  4. Calcul Scor Total: Sistem calculează scor ponderat (max 5)
  5. Clasificare: Sistem atribuie categorie valoare egală pe baza score
  6. Revizuire: HR + Manager revizuiesc și aprobă evaluări
  7. Finalizare: Versiune finală înregistrată, audit trail, dată finalizare
Output: Matrice evaluare posturilor cu categorii valoare egală
Rol principal: HR Specialist, Managers
Frecvență: Annual + ad-hoc (pentru noi posturi)

Workflow 2: Introducere Date Salariale

📊 Scopul: Colectarea și validarea datelor salariale pentru analiza transparenței

Pași:
  1. Import: HR importă date salariați (CSV, Excel) - pseudonimizate automat
  2. Validare: Sistem validează format, domenii, referențe externe (job_id, employee_id)
  3. Asociere: Sistem mapează salariații la posturile și categoriile lor
  4. Componente: HR introduce componente salariu (bază, bonus, beneficii) pe salariat
  5. Revizuire: Payroll + HR revizuiesc datele pentru acuratețe
  6. Approval: Aprobarea de CFO sau responsabil payroll
  7. Lock: Date salarii pentru perioada respectivă sunt locked (read-only)
Output: Bază de date completă salariale, gata pentru analiza
Rol principal: HR, Payroll, CFO
Frecvență: Lunar / Trimestrial

Workflow 3: Analiza Transparență Salarială

📈 Scopul: Analiză diferențe salariale și identificare necesității justificărilor

Pași:
  1. Calcul Diferențe: Sistem calculează salariu mediu femei vs bărbați per categorie
  2. Identificare Gap: Flagging diferențe ≥ 5% (threshold conform Directivă)
  3. Categorizare: Clasificare ca "Justificat", "Nejustificat", "Sub analiza"
  4. Raport Preliminar: HR primește raport cu gap-uri identificate
  5. Review Manager: Manager responsabil analiza și propune justificări
  6. Documente Suport: Ataşare documente (performanță, experiență, etc.)
  7. Compliance Review: Compliance Officer valida justificări vs Directivă
Output: Raport analiza cu justificări documentate
Rol principal: HR, Managers, Compliance Officer
Frecvență: Annual (minim)

Workflow 4: Planul de Măsuri Corective

🎯 Scopul: Plan acțiuni pentru reducerea diferențelor nejustificate

Pași:
  1. Identificare Disparități: Din analiza, selectare diferențe nejustificate
  2. Cauzele: HR analizează cauze (istoric, tip angajare, etc.)
  3. Plan Corective: Propuneri: majorări salariu, reclasificare, etc.
  4. Estimare Impact: Costuri, impact buget, efecte
  5. Aprobări: CFO, Director RH, Management
  6. Implementare: Executare măsuri, tracking progres
  7. Monitoring: Rapoarte de urmărire periodice
Output: Plan măsuri corective cu timeline și impact
Rol principal: HR, Management, CFO
Frecvență: Anual, cu review trimestrial

Workflow 5: Cereri Salariați & Drepturi Subiect

👤 Scopul: Gestionare cereri de informații de la salariați (Art. 10 Directivă)

Pași:
  1. Cerere: Salariat solicită info salariu/post (prin portal self-service)
  2. Autentificare: Salariat se autentifică, sistem verifica persoana
  3. Raport Personalizat: Sistem generează raport cu salariu (codificat), post, categorie
  4. Justificări Relevante: Inclusiv justificări care-l privesc direct
  5. Sending: Raport trimis salariatului în format securizat
  6. Logging: Audit trail - cine a cerut, când, ce a văzut
Output: Raport personalizat, securizat
Rol principal: Employee, HR (suport), System
Frecvență: On-demand (oricând solicita salariatul)

🔐 7. Conformitate & Securitate

Directiva UE 2023/970 - Conform Requirements

Art. 4 - Evaluare Obiectivă

  • ✓ Sistem evaluare pe criterii predefinite (competențe, efort, responsabilitate, condiții, complexitate, autonomie, impact)
  • ✓ Ponderi transparente și documentate
  • ✓ Scor total calculat obiectiv (1-5)
  • ✓ Classificare în categorii valoare egală bazată pe scor

Art. 5-7 - Justificări pentru Diferențe Salariale

  • ✓ Sistem detectează diferențe ≥ 5%
  • ✓ Mod input justificări cu template-uri predefine
  • ✓ Ataşare documente suport (performanță, experiență, etc.)
  • ✓ Workflow aprobare (HR → Manager → Compliance)
  • ✓ Plan corective pentru diferențe nejustificate

Art. 9 - Raportare la Autorități

  • ✓ Export raport oficial (Art. 9 alin. 1) cu date agregate
  • ✓ Format conform legislației (pe categorii, gen, etc.)
  • ✓ Pseudonimizare automată (fără nume salariați)
  • ✓ Audit trail - cine a generat raportul, când

Art. 10 - Drepturi Salariați

  • ✓ Portal self-service pentru cereri de informații
  • ✓ Răspuns complet în 30 de zile (suportat de sistem)
  • ✓ Informații relevante (salariu codificat, post, justificări)
  • ✓ Logging cereri și răspunsuri

GDPR - Protecția Datelor

Privacy by Design

  • ✓ Pseudonimizare automată: salariații nu sunt identificabili în analiza
  • ✓ Minimizare date: doar date necesare sunt stocate
  • ✓ Drepturi subiect: acces, corectare, ștergere (în limits legale)
  • ✓ Data retention: ștergere date după expirare termene legale

Security & Access Control

  • ✓ Autentificare: SSO, MFA (opțional)
  • ✓ Autorizare: Role-based (HR, Manager, Compliance, Employee)
  • ✓ Criptare: Transport (HTTPS), Storage (AES-256)
  • ✓ Audit logging: Toate acțiunile tracked (who, what, when)

Controlul Accesului (RBAC)

Rol Permisiuni Limitări
HR Specialist CRUD posturi, salarii, evaluări; generare rapoarte Nu poate modifica după lock
Manager View posturi + salarii (departament); evaluate posturi; suggest justificări Doar departament propriu; view salariu în persoană
Compliance Officer View toate datele; valida justificări; generează rapoarte oficiale Read-only pentru data operaționale
CFO Aproba date salarii; aproba plan corective; view financiar impact Nu poate modifica date după aproba
Employee (Self-service) View salariu propriu (codificat); cere informații (Art. 10) Doar proprii date; nu vede comparații

Audit & Logging

Audit Trail Complet:

  • Fiecare acțiune logged: User ID, Timestamp, Acțiune, Entitate, Valori vechi/noi
  • Impossibil de ștergere (append-only log)
  • Rapoarte audit pentru management și compliance
  • Alerting: Acțiuni sensibile (modificare salariu major, export date, etc.)

⚙️ 8. Tech Stack Recomandată

Backend

Framework & Runtime

  • Node.js + Express / Python + FastAPI
  • RESTful API cu JSON
  • Autentificare: JWT + OAuth2

Bază de Date

  • PostgreSQL (relațional, ACID)
  • Audit logging în tabelă separată
  • Row-level security (RLS)
  • Backups + disaster recovery

Caching & Performance

  • Redis pentru cache
  • Session storage
  • Rate limiting

Securitate

  • HTTPS + TLS 1.2+
  • Criptare AES-256 (storage)
  • CORS, CSP headers
  • SQL injection + XSS protection

Frontend

Framework SPA

  • React + TypeScript
  • State management: Redux / Zustand
  • Responsive design (mobile-first)

UI Components

  • Material-UI / TailwindCSS
  • Accessibility (WCAG 2.1 AA)
  • Dark mode support

Rapoarte & Analitică

  • Chart.js / D3.js pentru grafice
  • React Query pentru data fetching
  • Export PDF: jsPDF

Testing & QA

  • Unit tests: Jest
  • Integration tests: Cypress
  • Code coverage: target 80%+

Infrastructure & DevOps

Hosting & Deployment

  • Cloud: AWS / Azure / GCP
  • Container: Docker
  • Orchestration: Kubernetes (opțional)

CI/CD

  • GitHub Actions / GitLab CI
  • Automated testing
  • Code quality checks

Monitoring

  • Prometheus + Grafana
  • ELK Stack (logging)
  • Error tracking: Sentry
